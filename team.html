2. Image Finder — tìm ảnh & tìm mặt

Đăng nhập Gmail → Thêm từ Drive (folder shoot) → AI học → tìm theo mô tả hoặc mở folder để tìm mặt.

Mở Image Finder Mở folder Drive mẫu

3. Cách tìm mặt nhanh

  1. Trong Image Finder: đăng nhập Gmail → Thêm từ Drive → chọn folder shoot (Ctrl/Cmd+A).
  2. Đợi AI học nền (thanh dưới).
  3. Mở folder trong thư viện → nút Tìm mặt → upload ảnh chân dung hoặc dán link Drive công khai.
  4. App so mặt với từng ảnh (kể cả ảnh nhóm).
